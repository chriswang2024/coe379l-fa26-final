# Evidence-Backed Portfolio Assistant

COE 379L final project, Fall 2026 · Chris Wang and Aashvi Maithani

An evidence-backed portfolio chatbot using retrieval augmented generation and a Lean validator.

## Project Structure

| Folder | Purpose | Primary responsibility |
| --- | --- | --- |
| `app/web/` | Chat interface and citation display | Chris |
| `app/server/` | Python API, retrieval, and model integration | Aashvi |
| `checker/` | Lean validator, predicates, proof work, and checker tests | Chris |
| `corpus/` | Owner-approved corpus used by retrieval | Chris prepares; both use |
| `evaluation/benchmark/` | Benchmark questions, expected evidence, and scoring | Aashvi leads; both review |
| `evaluation/scripted/` | Scripted model responses and validation cases | Chris |
| `docs/` | Integration agreements and shared documentation | Both |
| `presentation/` | Demo and presentation materials | Both |
| `Proposal/` | Original proposal and flowchart | Both |
